## 001 · basis · kale
- **Opgave:** Turven favoriete kleur (elke | = 1 stem):
  ```
  rood   | | | |
  blauw  | | |
  ```
  Hoeveel stemmen heeft rood?
- **Antwoord:** 4
- **Hint:** Tel de streepjes bij rood, één voor één.
- **Sterkere hint:** Rood heeft vier | -streepjes.
- **Fout-hints:** 3 → Dat is blauw. · 7 → Je telde rood en blauw samen. · 1 → Tel alle streepjes bij rood.
- **Ouderzin:** Je kind telt turfstreepjes bij rood.
- **Getallenruimte:** 0–20
- **Context:** laag
- **Visual:** ja

## 002 · basis · kale
- **Opgave:** Tabel → hokjes. Peer heeft 3 kinderen. Hoeveel hokjes kleur je bij peer?
  ```
  peer  □ □ □ □ □ □
  ```
- **Antwoord:** 3
- **Hint:** Elk kind = 1 hokje. Wat staat er bij peer?
- **Sterkere hint:** 3 kinderen → kleur precies 3 hokjes.
- **Fout-hints:** 6 → Dat is de lengte van de lege rij, niet het aantal. · 2 → Te weinig. · 4 → Te veel.
- **Ouderzin:** Je kind zet tabelgetal 3 om in 3 in te kleuren hokjes.
- **Getallenruimte:** 0–10
- **Context:** laag
- **Visual:** ja

## 003 · basis · invullen
- **Opgave:** Turven met groepjes van 5 (vijfde streep dwars; ||||| = 5):
  ```
  hond  |||||  | |
  ```
  (een bundeltje van 5 + twee losse streepjes)
  Vul in: er zijn □ stemmen voor hond.
- **Antwoord:** 7
- **Hint:** Eerst het bundeltje van 5, daarna de losse streepjes erbij.
- **Sterkere hint:** 5 + 2 = 7.
- **Fout-hints:** 5 → Je telde alleen het bundeltje. · 2 → Je telde alleen de losse streepjes. · 6 → Net één te weinig; 5+2=7.
- **Ouderzin:** Je kind leest een turf met bundeltje van 5 + 2 als 7.
- **Getallenruimte:** 0–20
- **Context:** laag
- **Visual:** ja

## 004 · toepassen · meerkeuze
- **Opgave:** Stemmen op fruit geturfd:
  ```
  appel  |||||
  peer   | | |
  banaan |||||  |
  ```
  Welke tabel klopt?
- **Antwoord:** A
- **Opties:**
  - A) appel 5 · peer 3 · banaan 6
  - B) appel 5 · peer 3 · banaan 5
  - C) appel 4 · peer 3 · banaan 6
  - D) appel 5 · peer 5 · banaan 6
- **Hint:** ||||| = 5. Tel daarna de losse streepjes.
- **Sterkere hint:** Appel = 5. Peer = 3. Banaan = 5+1 = 6.
- **Fout-hints:** B → Banaan heeft nog één los streepje: 6, niet 5. · C → Appel is een vol bundeltje: 5, niet 4. · D → Peer heeft 3, niet 5.
- **Ouderzin:** Je kind zet turfstreepjes om in de juiste tabelgetallen.
- **Getallenruimte:** 0–20
- **Context:** midden

## 006 · toepassen · verslepen
- **Opgave:** Koppel elke turf of tabel aan het juiste aantal / diagram-deel.
  - |||||  | |  → ?
  - tabel “kat: 4” → hoeveel hokjes kleuren? → ?
  - | | |  → ?
  - |||||  |||||  → ?
- **Antwoord:** ||||| | | → 7 · kat: 4 → 4 hokjes · | | | → 3 · ||||| ||||| → 10
- **Hint:** Bundeltje ||||| = 5. Tel losse streepjes erbij. Tabelgetal = aantal hokjes.
- **Sterkere hint:** 5+2=7. Kat→4. Drie streepjes→3. Twee bundeltjes→10.
- **Fout-hints:** |||||+| | → 5 → Je vergat de twee losse. · kat 4 → 5 hokjes → Kleur precies 4. · ||| → 5 → Er staan drie streepjes. · twee bundels → 5 → Twee×5 = 10.
- **Ouderzin:** Je kind koppelt turven en tabelgetallen aan aantallen/hokjes.
- **Getallenruimte:** 0–20
- **Context:** midden
- **Visual:** ja

## 007 · kritisch · verslepen
- **Opgave:** Koppel elke zin aan klopt / klopt niet.
  - “||||| betekent 5 stemmen.” → ?
  - “Van tabel ‘hond: 3’ kleur je 3 hokjes in het staafdiagram.” → ?
  - “Turf | | | | | | (zes losse) is hetzelfde aantal als |||||  | .” → ?
  - “Bij een voorgestructureerd diagram mag je meer hokjes kleuren dan het tabelgetal.” → ?
- **Antwoord:** “||||| = 5” → klopt · “hond 3 → 3 hokjes” → klopt · “zes losse = ||||| |” → klopt · “meer hokjes dan tabel” → klopt niet
- **Hint:** Bundeltje = 5. Tabel = hokjes 1-op-1. Zes = 5+1. Niet méér kleuren dan het getal.
- **Sterkere hint:** De eerste drie kloppen. Te veel hokjes kleuren klopt niet.
- **Fout-hints:** ||||| = 5 → klopt niet → Dat klopt wél. · 3→3 hokjes → klopt niet → Dat is juist de regel. · zes = 5+1 → klopt niet → 6 = 6, dat klopt wél. · meer kleuren → klopt → Nee, je kleurt precies het tabelgetal.
- **Ouderzin:** Je kind checkt regels over turven en overzetten naar een staafdiagram.
- **Getallenruimte:** 0–20
- **Context:** midden
- **Visual:** ja
